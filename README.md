# Tectum
Learning how to use github for the tectum project. 

This repo is associated with our manuscript that examines how optic nerve innervation appears to activate Wnt/beta-catenin pathway activity to influences cell proliferation within the optic tectum.  Hagen et al., 2026 

Each figure in the main text that has quantitative analyses (Figs 2-8) has a corresponding R-markdown file and multiple csv files.
- Each Rmd is named so that it begins with the figure it was used to generate, with one exception. We used a single Rmd file for all of the supplementary files; it begins with 9.
- Each csv is named so that it begins with the number of the Figure it is associated with except that all supplementary files begin with 9. 

All raw images are stored and backed-up onsite at Reed College. We are working on finding a way to publicly share all of the image files in a reasonably accessible and approachable way. This document will be updated if that is the case. If you would like to use our data for something, please contact Kara: cervenyk@reed.edu
