# Tectum
Learning how to use github for the tectum project. 

This repo is associated with our manuscript, Optic nerve innervation promotes Wnt/B-catenin pathway activity and progenitor cell proliferation in the zebrafish optic tectum (Hagen et al., 2026). 

Each figure in the main text with quantitative analyses (Figs 2-8) has a corresponding R-markdown file and multiple csv files.
- Each Rmd is named so that it begins with the figure it was used to generate, with one exception. A single Rmd file, which begins with the number 9, was used to generate all of the supplementary plots and quantitative analyses.
- Each csv is named so that it begins with the number of the Figure it is associated with the exception that all files associated with supplementary figures begin with the number 9. 

All raw images are stored and backed-up onsite at Reed College. We are working on finding a way to publicly share all of the image files in a reasonably accessible and approachable way. This document will be updated when anything changes.
